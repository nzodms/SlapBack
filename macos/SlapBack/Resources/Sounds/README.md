# SlapBack — Sound Files

Add your MP3 files here. Each file must be added to the Xcode target (check "Add to targets: SlapBack" when adding).

| Filename     | Used by preset       | Description                          |
|-------------|----------------------|--------------------------------------|
| scream.mp3  | Spacebar scream      | Short sharp scream, 0.5–1.5s        |
| ouch.mp3    | Spam clicks          | Cartoon "ouch!" or pain sound        |
| slap.mp3    | Tap desk             | Physical slap or impact sound        |
| demon.mp3   | Caps Lock demon      | Deep distorted voice / demon growl   |

## Format

- Format: MP3, 44.1kHz, stereo or mono
- Length: 0.5s – 2.0s (shorter = snappier)
- Level: normalized to -1 dBFS peak

## Source suggestions

Free sounds: freesound.org (search CC0 license)
Or record your own voice and process with Audacity.
